# نظام إدارة خريجي جامعة البطانة — النسخة المتكاملة

## المميزات
- لوحة تحكم وإحصائيات حسب الأقسام.
- بحث متقدم بالاسم والأرقام والقسم والتخصص والهاتف والإيميل.
- عرض ملف الخريج بالتفصيل.
- إضافة وتعديل وحذف الخريجين.
- استيراد وتصدير Excel.
- إنشاء نسخة احتياطية ZIP لقاعدة البيانات وExcel.
- تقرير PDF للخريج.
- نظام مستخدمين وصلاحيات.
- سجل تدقيق للعمليات.
- بوابة استعلام عامة للخريج برقم التسجيل.
- قاعدة بيانات SQLite أكثر ثباتاً من الاعتماد على Excel فقط.
- واجهة عربية متجاوبة للهاتف والكمبيوتر.

## التشغيل
```bash
pip install -r requirements.txt
python app.py
```

بيانات المدير الافتراضية: `admin` / `1234`

> يفضل تغيير كلمة المرور قبل التشغيل الفعلي على الإنترنت.
